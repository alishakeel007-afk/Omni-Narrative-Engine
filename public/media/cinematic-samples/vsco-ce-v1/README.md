# VSCO CE v1 cinematic sample subset

This directory contains the compact recorded-instrument subset used by Omni-Narrative Engine's browser-based cinematic score renderer.

- Source: [VSCO Community Edition](https://github.com/sgossner/VSCO-2-CE)
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Attribution: not legally required by CC0; the application credits VSCO Community Edition and the recorded Upright Piano credits Simon Dalzell / Ivy Audio.

The authoritative versioned manifest is `lib/audio/sample-catalog.ts`. It records original raw-source URLs, creators where supplied, license, SHA-256 checksums, byte sizes, root MIDI notes, and permitted scene-mood use. Do not replace or add audio here without updating that manifest and its integrity test.
