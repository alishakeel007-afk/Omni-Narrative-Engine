# Final Demonstration Script

## Preparation

1. Use a disposable demo account and short prepared story ideas.
2. Prepare one saved Guided and one saved Custom project as fallback material.
3. Confirm the application is running and My Projects is reachable.
4. Describe Stage 8 accurately as a synchronized browser preview, not MP4 export.

## Demonstration

### Login and entry

1. Log in and show Home.
2. Select **Open Video Studio**.
3. Show the Guided/Custom selector and explain: Guided is structured; Custom is manual-first.

### Guided Video Studio

1. Choose Guided and identify all eight stages.
2. At Setup, select language, genre, tone, and a short idea.
3. Generate a story only if live-provider access is available; otherwise open the prepared Guided project through My Projects.
4. Show Story Review and edit a scene/dialogue in Scenes & Dialogues.
5. Show an existing voice clip, visual status, and scene-aware music decision. Avoid provider calls unless planned.
6. Open Video Preview; use Play, Pause, Restart, and current-scene/progress controls. Explain ducking only while demonstrating saved playable media.

### Save and resume

1. Open Profile → My Projects.
2. Show Guided/Custom labels, In Progress/Completed grouping, saved stage, and Resume/Watch Story actions.
3. Resume a prepared Guided project to demonstrate project-aware restoration.

### Custom Story Builder

1. Return to mode selection and choose Custom.
2. Edit title, manually edit narration/dialogue, and reorder or add a scene.
3. Use **Suggest 3 Next Scenes** only if provider access is available; otherwise explain that it is optional.
4. Save to My Projects and show confirmed save state.
5. Show Custom multimedia controls and optional intentional silence using prepared media.
6. Open the Custom browser preview.

## Failure fallback

- If story AI fails, explain the Groq-primary/Gemini-fallback design and use a prepared project. Do not repeatedly retry.
- If media generation fails, show the controlled retry/error state and existing saved media.
- If music is unavailable, demonstrate intentional silence or a saved score.
- If autoplay is blocked, press Play manually and explain browser policy.

## Closing statement

Omni-Narrative Engine demonstrates account-owned narrative authoring, media orchestration, persistence, and synchronized browser preview. MP4 rendering/export is future work and outside the implemented scope.
