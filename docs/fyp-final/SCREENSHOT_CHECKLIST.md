# Screenshot Checklist

Use a disposable project. Obscure personal data, IDs, raw URLs with tokens, and all secrets.

## Screens

- Home page with Video Studio call to action.
- Guided/Custom mode selector with both local image cards.
- Profile menu with My Projects.
- Guided Setup, Story Review, Scenes & Dialogues, Voice Audio, Visual Generation, Background Music, and Video Preview.
- A saved image, a readable status/warning, a score or intentional-silence state, and preview controls/progress.
- Custom Story Builder title/editor, optional suggestion cards, and save state.
- Custom multimedia controls and Custom preview.
- My Projects In Progress with Guided/Custom labels and Resume action.
- Completed/Needs Attention state if a disposable eligible project exists.
- Sanitized test/TypeScript terminal output.
